## 🌟 Featured Projects

### 🔍 [Glass Classification](https://github.com/ErenEroglu61/GlassClassification)
A machine learning web app that predicts the type of glass based on its chemical properties, built on the [UCI Glass dataset](https://www.kaggle.com/datasets/uciml/glass). The project covers the full pipeline — from data preprocessing and model training in a Jupyter notebook to serving predictions through a Flask-based web interface, with a trained classifier, label encoder, and scaler ready to go.

### 🎓 [ClosingProjectForMl](https://github.com/ErenEroglu61/ClosingProjectForMl)
My closing project for a 100-day Machine Learning course, combining a trained ML model with a Flask web app so users can interact with predictions directly from the browser.
